เลือกด่านภารกิจ

📚 ความรู้ก่อนเริ่มเกม: สัญลักษณ์ผังงาน (Flowchart)

ผังงานคือการใช้รูปภาพสัญลักษณ์บอกลำดับขั้นตอนการทำงาน

เริ่ม / จบ

1. วงรี (Oval / Capsule)

ชื่อ: จุดเริ่มต้นและจุดสิ้นสุด (Start / End)

ใช้ระบุจุดเริ่มต้นแรกสุด และจุดสิ้นสุดสุดท้ายของขั้นตอนการทำงานทั้งหมด

การทำงาน

2. สี่เหลี่ยมผืนผ้า (Rectangle)

ชื่อ: การประมวลผล / ขั้นตอนการทำงาน (Process)

ใช้สำหรับการคำนวณ การกำหนดค่า หรือขั้นตอนการปฏิบัติตามปกติ

รับ / แสดงผล

3. สี่เหลี่ยมด้านขนาน (Parallelogram)

ชื่อ: การรับข้อมูลหรือแสดงผลข้อมูล (Input / Output)

ใช้รับข้อมูลเข้ามาทำงาน หรือแสดงผลลัพธ์ออกทางจอภาพ/เครื่องพิมพ์

การตัดสินใจ

4. สี่เหลี่ยมข้าวหลามตัด (Diamond)

ชื่อ: การตัดสินใจ / ตรวจสอบเงื่อนไข (Decision)

ใช้เลือกเส้นทางทำงานโดยตรวจสอบเงื่อนไข ซึ่งจะมีทางออก 2 ทาง คือ "ใช่" หรือ "ไม่ใช่"

5. ลูกศร (Flowline Arrow)

ชื่อ: ทิศทางการทำงาน (Flowline)

ใช้เชื่อมต่อสัญลักษณ์ต่างๆ เพื่อบอกลำดับและทิศทางของขั้นตอนตั้งแต่เริ่มต้นจนสิ้นสุด
